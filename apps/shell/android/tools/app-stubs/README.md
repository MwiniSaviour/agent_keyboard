# app-stubs

Compile-time stand-ins used **only** by `tools/verify-app.sh` (the sandbox/CI fallback that type-checks
the app module without Gradle or the Android SDK). They are never packaged; the Gradle build uses the
real artifacts.

- `androidx/appcompat/app/AppCompatActivity.java` — supertype of Capacitor's `BridgeActivity`.
- `androidx/sqlite/db/*.java` — supertypes of SQLCipher's `SQLiteDatabase` / `SQLiteOpenHelper`
  (only their names matter to Kotlin callers; SQLCipher's real Java sources supply every member we call).

`R`, `BuildConfig` and the AIDL interfaces are generated by the script from the real `res/`,
flavor config and `.aidl` files, so they cannot drift from the sources.
